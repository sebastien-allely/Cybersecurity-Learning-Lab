# Politique de sécurité

## Objectif

La sécurité est au cœur de Cybersecurity Learning Lab.

Ce dépôt a pour vocation de diffuser des pratiques de cybersécurité défensive. Malgré le soin apporté à la rédaction, une erreur, une mauvaise configuration ou une vulnérabilité peuvent être identifiées.

Si vous pensez avoir découvert un problème de sécurité, merci de le signaler de manière responsable.

---

# Signaler une vulnérabilité

Vous pouvez signaler notamment :

* une erreur de configuration pouvant diminuer le niveau de sécurité ;
* une mauvaise pratique de sécurité ;
* une vulnérabilité dans un script publié ;
* une recommandation devenue obsolète ;
* une référence officielle plus récente.

Merci de fournir, si possible :

* une description du problème ;
* son impact potentiel ;
* les étapes permettant de le reproduire ;
* une proposition de correction si vous en disposez.

---

# Traitement des signalements

Chaque signalement sera :

* analysé ;
* reproduit lorsque cela est possible ;
* corrigé si nécessaire ;
* documenté dans le journal des modifications.

La qualité et la sécurité du contenu priment sur la rapidité de publication.

---

# Périmètre

Cette politique concerne uniquement :

* les scripts présents dans ce dépôt ;
* les configurations proposées ;
* la documentation publiée.

Elle ne concerne pas les logiciels tiers (Proxmox VE, Zabbix, GLPI, Fail2ban, CrowdSec, ClamAV, etc.), dont les vulnérabilités doivent être signalées à leurs éditeurs respectifs.

---

# Divulgation responsable

Merci de ne pas publier publiquement une vulnérabilité avant qu'elle ait pu être analysée et corrigée lorsqu'elle concerne directement ce projet.

Une divulgation responsable contribue à améliorer la qualité du référentiel tout en protégeant ses utilisateurs.

---

# Références

Les mises à jour de sécurité et les corrections s'appuient prioritairement sur :

* les documentations officielles des logiciels ;
* les publications de l'ANSSI ;
* les publications du NIST ;
* les recommandations de l'OWASP ;
* les informations de MITRE ATT&CK lorsque cela est pertinent.
