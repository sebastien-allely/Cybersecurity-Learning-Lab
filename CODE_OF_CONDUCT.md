## Notre engagement

Cybersecurity Learning Lab est un projet ouvert à toutes les personnes souhaitant apprendre, partager ou améliorer leurs compétences en cybersécurité défensive.

Les échanges doivent rester respectueux, constructifs et centrés sur les aspects techniques et pédagogiques.

---

# Comportements attendus

J'encourage notamment :

* le respect des autres contributeurs ;
* les critiques argumentées et constructives ;
* le partage de connaissances ;
* la citation des sources ;
* la bienveillance envers les personnes débutantes.

---

# Comportements inacceptables

Ne sont notamment pas acceptés :

* les attaques personnelles ;
* les propos discriminatoires ;
* le harcèlement ;
* les contenus sans rapport avec le projet ;
* la diffusion volontaire d'informations trompeuses.

---

# Résolution des conflits

En cas de désaccord technique, les échanges devront s'appuyer sur :

* des tests reproductibles ;
* des référentiels reconnus ;
* des documentations officielles.

L'objectif est de privilégier les faits plutôt que les opinions.

---

# Objectif

La finalité du projet est de favoriser l'apprentissage, la qualité technique et le partage de connaissances dans un environnement respectueux.
