# Analyse d'un incident Active Directory

**Nom du document** : Analyse d'un incident Active Directory
**Technologie** : Active Directory Domain Services
**Catégorie** : Lab pratique
**Objectif** : Analyser un incident affectant un domaine Active Directory à partir des événements, journaux et symptômes observés.
**Auteur** : Sébastien ALLELY
**Version** : 1.0
**Date de dernière modification** : 2026-09-13

---

## 1. Objectif

Reconstituer la chronologie d'un incident affectant l'annuaire et déterminer les éléments techniques à l'origine du problème.

---

## 2. Analyse

Étudier :

* les événements d'authentification ;
* les comptes concernés ;
* les changements de configuration ;
* les événements système ;
* DNS ;
* Kerberos ;
* les services Active Directory.

---

## 3. Approche Blue Team

Identifier les indicateurs observables, qualifier l'incident et déterminer les actions de confinement et de restauration.

---

## 4. Approche Red Team

Reproduire uniquement dans le laboratoire un événement contrôlé permettant de vérifier la capacité de détection et d'analyse.

---

## 5. Compte rendu

Produire une chronologie, identifier la cause retenue et proposer des mesures préventives.
