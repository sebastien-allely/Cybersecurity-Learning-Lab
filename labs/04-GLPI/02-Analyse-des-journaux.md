# Analyse des journaux GLPI

**Nom du document** : Analyse des journaux GLPI
**Technologie** : GLPI / Apache / MariaDB
**Catégorie** : Lab pratique
**Objectif** : Corréler les journaux GLPI, Apache, PHP et MariaDB afin d'identifier l'origine d'un incident applicatif.
**Auteur** : Sébastien ALLELY
**Version** : 1.0
**Date de dernière modification** : 2026-09-13

---

## 1. Objectif

Construire une chronologie d'un incident applicatif en corrélant plusieurs sources de journaux.

---

## 2. Sources

Analyser selon le scénario :

* journaux GLPI ;
* Apache ;
* PHP ;
* MariaDB ;
* système Linux.

---

## 3. Méthode

Identifier :

1. premier événement anormal ;
2. erreur principale ;
3. événements associés ;
4. conséquence ;
5. retour à la normale.

---

## 4. Critères de réussite

L'apprenant doit relier les événements provenant des différentes couches et identifier la cause probable.
