# 07 - Réévaluation et amélioration

---

## 1. Principe

Le laboratoire doit évoluer lorsque :

* les risques changent ;
* les technologies évoluent ;
* une vulnérabilité apparaît ;
* un mécanisme devient obsolète ;
* un exercice révèle une faiblesse ;
* une nouvelle connaissance est acquise.

---

## 2. Réévaluation

La réévaluation peut porter sur :

* actifs ;
* menaces ;
* risques ;
* criticité ;
* mesures ;
* supervision ;
* procédures ;
* exercices.

---

## 3. Amélioration continue

La démarche suit le principe :

```text
Planifier
   ↓
Mettre en œuvre
   ↓
Vérifier
   ↓
Améliorer
   ↓
Réévaluer
```

---

## 4. Traçabilité

Les modifications importantes doivent être documentées et, lorsqu'elles concernent le dépôt, versionnées dans Git.

---

## 5. Objectif final

L'objectif n'est pas d'accumuler des technologies.

Le laboratoire doit progressivement devenir :

* plus cohérent ;
* plus observable ;
* plus sécurisé ;
* plus reproductible ;
* plus pédagogique.
