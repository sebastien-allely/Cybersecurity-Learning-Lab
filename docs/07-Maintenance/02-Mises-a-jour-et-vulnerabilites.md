## 1. Objectif

Les systèmes du laboratoire doivent être maintenus afin de réduire l'exposition aux vulnérabilités connues.

---

## 2. Identification

La maintenance doit permettre d'identifier :

* les composants installés ;
* leurs versions ;
* les mises à jour disponibles ;
* les vulnérabilités pertinentes ;
* les dépendances importantes.

---

## 3. Évaluation

Une vulnérabilité ne doit pas être évaluée uniquement selon son score.

Il faut également considérer :

* l'exposition ;
* l'actif concerné ;
* la criticité ;
* les mesures compensatoires ;
* la possibilité d'exploitation ;
* l'impact potentiel.

---

## 4. Après mise à jour

Une mise à jour doit être suivie de vérifications :

* service ;
* configuration ;
* supervision ;
* sécurité ;
* sauvegarde ;
* fonctionnement des dépendances.

---

## 5. Documentation

Les modifications importantes de version doivent être répercutées dans les documents lorsque leur contenu devient obsolète.
