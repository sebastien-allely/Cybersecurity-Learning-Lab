# 4. Dépendances

Les décisions de sécurité appliquées à GLPI01 sont cohérentes avec les référentiels consacrés à :

- Apache HTTP Server ;
- MariaDB ;
- Active Directory ;
- Ubuntu Server ;
- ZABBIX01.

Le durcissement de GLPI01 ne remplace pas celui de ces composants, il le complète.

---

# 5. Conclusion

La sécurité de GLPI01 résulte de la combinaison de décisions portant à la fois sur l'application, son environnement technique et les données métier qu'elle héberge.
