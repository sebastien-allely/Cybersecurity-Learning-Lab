# 1. Objectif

Ce document recense les référentiels, documentations officielles et ressources techniques ayant servi à la conception du référentiel Apache HTTP Server.

Les décisions présentées dans les documents de ce dossier reposent sur des sources reconnues, régulièrement mises à jour et faisant autorité dans leur domaine.

---

# 2. Référentiels de cybersécurité

Les référentiels suivants constituent le socle méthodologique du projet :

- ANSSI — Guide d'hygiène informatique
- ANSSI — Recommandations relatives à la sécurisation des services Internet
- EBIOS Risk Manager
- NIST Cybersecurity Framework (CSF)
- ISO/IEC 27001
- ISO/IEC 27002

---

# 3. Documentation officielle

Les décisions techniques relatives à Apache doivent s'appuyer prioritairement sur la documentation officielle :

- Apache HTTP Server Documentation
- Apache Security Tips
- Apache SSL/TLS Documentation

---

# 4. Documentation des composants associés

Les technologies suivantes peuvent influencer la sécurité d'Apache :

- OpenSSL
- Debian
- Ubuntu Server
- PHP
- Let's Encrypt

Leurs documentations officielles doivent être consultées lors des évolutions du référentiel.

---

# 5. Guides techniques

Le projet s'appuie également sur plusieurs guides techniques reconnus :

- SOCLE — Stéphane Robert
- CIS Benchmarks (lorsqu'un benchmark est disponible)
- OWASP (notamment pour les applications Web publiées)

---

# 6. Veille

Une veille régulière doit être assurée concernant :

- les nouvelles vulnérabilités ;
- les évolutions d'Apache ;
- les évolutions de TLS ;
- les recommandations ANSSI ;
- les mises à jour du SOCLE de Stéphane Robert.

Les décisions du référentiel devront être réévaluées en fonction de ces évolutions.

---

# 7. Conclusion

Le présent référentiel ne constitue pas une source autonome.

Il s'appuie sur des référentiels et documentations faisant autorité afin de garantir la pertinence et la pérennité des décisions de sécurité retenues.
