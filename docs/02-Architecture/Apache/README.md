# Objectif pédagogique

Le lecteur doit être capable de comprendre :

- pourquoi Apache est utilisé ;
- quels actifs il protège ;
- quels risques sont pris en compte ;
- quelles décisions de sécurité sont retenues ;
- comment ces décisions sont maintenues dans le temps.

L'objectif n'est pas de reproduire une configuration mais de comprendre la démarche de conception qui la justifie.
