## Objectif

Ce dossier documente l'architecture et les choix de conception d'Active Directory au sein du projet Cybersecurity-Learning-Lab.

Active Directory constitue le référentiel central des identités du laboratoire. Il fournit les services d'authentification, d'autorisation, de résolution de noms et d'application des stratégies de sécurité.

Le présent dossier décrit les actifs protégés, les risques identifiés et les décisions d'architecture retenues.
