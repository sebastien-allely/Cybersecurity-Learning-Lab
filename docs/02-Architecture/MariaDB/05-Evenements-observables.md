## Objectif

Identifier les événements permettant une supervision pertinente.

---

# Disponibilité

- arrêt du service ;
- redémarrage ;
- crash InnoDB ;
- saturation des connexions.

---

# Sécurité

- connexion root ;
- échecs d'authentification ;
- création de comptes ;
- suppression de comptes ;
- modification des privilèges.

---

# Données

- corruption de tables ;
- erreurs InnoDB ;
- restauration ;
- sauvegarde.

---

# Performances

- temps de réponse ;
- connexions simultanées ;
- saturation mémoire ;
- saturation disque.

---

# Conclusion

Un événement n'est retenu que s'il permet une décision opérationnelle.
