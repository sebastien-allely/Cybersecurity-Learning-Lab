# Hardening MariaDB

## 1. Objectif

Ce dossier présente les mesures de durcissement appliquées à MariaDB afin de réduire sa surface d'attaque, protéger les données et maintenir un niveau de sécurité cohérent avec son rôle dans l'infrastructure.

Le durcissement est organisé par domaines afin de faciliter la compréhension, l'application et la vérification des mesures.
