---

## 1. Objectif

Les modèles permettent de standardiser certaines productions du laboratoire.

Ils peuvent notamment concerner :

* exercices ;
* procédures ;
* comptes rendus ;
* analyses ;
* documentation technique.

---

## 2. Emplacement

Les modèles réutilisables sont conservés dans le répertoire :

```text
templates/
```

lorsqu'ils existent.

---

## 3. Cohérence

Un modèle doit rester cohérent avec :

* le guide de rédaction ;
* les conventions du dépôt ;
* la structure documentaire ;
* les processus de contribution.

---

## 4. Évolution

Les modèles doivent être modifiés lorsqu'une évolution du projet rend leur structure obsolète.
