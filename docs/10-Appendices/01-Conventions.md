## 1. Nommage

Les noms des composants doivent rester cohérents avec leur rôle dans le laboratoire.

---

## 2. Documentation

Les documents techniques utilisent une numérotation lorsque celle-ci permet de rendre leur progression explicite.

Les README servent de points d'entrée aux répertoires.

---

## 3. Versionnement

Les éléments destinés à être réutilisés ou modifiés doivent être versionnés lorsque cela est pertinent.

---

## 4. Configuration

Une configuration publiée doit être identifiable et documentée.

Les secrets et données sensibles ne doivent jamais être intégrés au dépôt.

---

## 5. Cohérence

Les conventions doivent être appliquées de manière cohérente entre :

* documentation ;
* configurations ;
* scripts ;
* supervision ;
* exercices.
