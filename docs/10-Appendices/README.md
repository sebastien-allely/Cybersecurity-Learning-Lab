# 1. Objectif

Les appendices regroupent des informations complémentaires qui ne nécessitent pas un document principal dédié.

Ils ne doivent pas servir à contourner l'organisation du référentiel.

---

# 2. Contenu

Ils peuvent notamment contenir :

* conventions ;
* aide-mémoires ;
* matrices ;
* tableaux de correspondance ;
* modèles ;
* informations transversales.

---

# 3. Principe

Une information importante concernant une technologie doit rester dans la documentation de cette technologie.

Les appendices sont réservés aux informations transversales.

---

# 4. Évolution

Un appendix peut être créé lorsqu'une information est :

* réutilisée dans plusieurs domaines ;
* suffisamment stable ;
* utile à plusieurs parcours ;
* difficile à positionner dans une seule catégorie.

Les informations devenues suffisamment importantes doivent être déplacées vers une documentation dédiée.
