# 1. Objectif

Le Learning Path aide l'apprenant à déterminer dans quel ordre utiliser les ressources du laboratoire.

Le dépôt est organisé par domaines techniques.

Le Learning Path est organisé par progression pédagogique.

---

# 2. Progression générale

```text
Comprendre
    ↓
Concevoir
    ↓
Installer
    ↓
Durcir
    ↓
Protéger
    ↓
Superviser
    ↓
Détecter
    ↓
Investiguer
    ↓
Remédier
    ↓
Maintenir
    ↓
Automatiser
```

---

# 3. Ressources utilisées

Les parcours s'appuient notamment sur :

```text
01-Methode-de-conception
02-Architecture
03-Hardening
04-Protection
05-Monitoring
06-Incident-Response
07-Maintenance
08-Exercices
```

---

# 4. Principe

L'apprenant ne doit pas nécessairement parcourir l'intégralité du dépôt dans l'ordre numérique.

Le parcours dépend de son objectif.

Un administrateur peut commencer par l'architecture et le hardening.

Un apprenant orienté sécurité peut progresser vers la protection, la détection et la réponse à incident.
