# 05 - Parcours automatisation et amélioration

Ce parcours vise à réduire les tâches répétitives et à améliorer la reproductibilité du laboratoire.

## Étapes

```text
Identifier une tâche répétitive
        ↓
Définir le résultat attendu
        ↓
Automatiser
        ↓
Tester
        ↓
Superviser
        ↓
Documenter
        ↓
Améliorer
```

## Ressources

Le parcours s'appuie notamment sur :

```text
automation/
zabbix/
docs/07-Maintenance/
```

## Technologies

Selon le besoin, l'automatisation peut utiliser :

* Bash ;
* PowerShell ;
* Python ;
* configurations versionnées.

## Objectif final

L'apprenant doit être capable d'identifier une tâche automatisable et de produire une automatisation contrôlée, testable et documentée.
