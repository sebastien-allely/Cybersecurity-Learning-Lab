# 01 - Parcours de découverte

Le parcours de découverte est destiné à comprendre la logique générale du laboratoire avant d'entrer dans les détails techniques.

## Étapes

### 1. Comprendre le projet

Lire :

* README principal ;
* méthode de conception ;
* présentation de l'architecture.

### 2. Comprendre les composants

Explorer les technologies documentées dans :

```text
docs/02-Architecture/
```

### 3. Comprendre la sécurité

Consulter :

```text
docs/03-Hardening/
docs/04-Protection/
```

### 4. Observer

Découvrir :

```text
docs/05-Monitoring/
```

### 5. Pratiquer

Comprendre et pratiquer

### Objectif final

Être capable d'expliquer :

* ce qu'est le laboratoire ;
* quels sont ses composants ;
* pourquoi ils sont présents ;
* comment ils sont protégés ;
* comment leur état est observé.
