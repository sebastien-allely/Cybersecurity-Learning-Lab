# 03 - Parcours détection et supervision

Ce parcours est orienté vers l'observation, la détection et l'analyse des événements.

## Étapes

```text
Protection
    ↓
Monitoring
    ↓
Alertes
    ↓
Qualification
    ↓
Investigation
```

## Ressources principales

* CrowdSec ;
* Fail2ban ;
* ClamAV ;
* AIDE ;
* Zabbix ;
* journaux système ;
* réponse à incident.

## Exercices

L'apprenant doit notamment apprendre à :

* provoquer un événement contrôlé ;
* observer les traces ;
* identifier l'alerte ;
* corréler plusieurs sources ;
* qualifier l'événement ;
* déterminer la réponse appropriée.

## Objectif final

Être capable de passer d'un événement technique à une analyse structurée et argumentée.
