# 02 - Parcours administration sécurisée

Ce parcours est destiné à développer les compétences d'administration système et réseau orientées sécurité.

## Étapes

```text
Méthode de conception
        ↓
Architecture
        ↓
Hardening
        ↓
Protection
        ↓
Monitoring
        ↓
Maintenance
```

## Ressources principales

* architecture Debian ;
* architecture Proxmox VE ;
* architecture Active Directory ;
* architecture GLPI ;
* durcissement ;
* SSH ;
* mécanismes de protection ;
* supervision ;
* maintenance.

## Exercices

Les exercices doivent progressivement demander à l'apprenant de :

* installer ;
* configurer ;
* durcir ;
* vérifier ;
* superviser ;
* diagnostiquer.

## Objectif final

Être capable de concevoir et maintenir un système correctement administré et sécurisé en justifiant les principales décisions prises.
