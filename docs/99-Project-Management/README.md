## Principes de gestion

Le projet utilise Git pour assurer le suivi des modifications et permettre la revue des évolutions.

Les modifications importantes doivent être :

* identifiables ;
* documentées ;
* vérifiables ;
* cohérentes avec l'architecture du projet ;
* validées avant leur intégration dans les branches principales.

La documentation constitue la référence pour comprendre les choix effectués et leur état de mise en œuvre.
