# Historique

## [0.1.0] — 07/08/2026

### Création initiale du dépôt

Mise en place de la première version structurée du **Cybersecurity-Learning-Lab**.

Cette version comprend notamment :

* la documentation méthodologique ;
* l'architecture du laboratoire ;
* les documents de hardening ;
* les mécanismes de protection ;
* la supervision et le monitoring ;
* la réponse à incident ;
* la maintenance ;
* les exercices pédagogiques ;
* les parcours d'apprentissage ;
* les annexes ;
* les références ;
* la documentation de gestion du projet ;
* les éléments d'automatisation ;
* les éléments dédiés à Zabbix.

Cette version constitue la base documentaire et technique destinée à être publiée publiquement.

---

# Convention

Les évolutions importantes du projet seront ajoutées à ce fichier lors des modifications significatives de l'architecture, de la documentation, des mécanismes de sécurité, des automatisations ou des parcours pédagogiques.

Les changements mineurs de correction typographique ou de mise en forme peuvent ne pas faire l'objet d'une entrée dédiée.
