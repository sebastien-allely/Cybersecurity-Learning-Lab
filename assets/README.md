## 1. Objectif

Le répertoire `assets` contient les ressources statiques utilisées par le projet **Cybersecurity-Learning-Lab**.

Ces ressources peuvent notamment être utilisées pour accompagner la documentation ou présenter certains éléments du laboratoire.

---

## 2. Organisation

Les ressources doivent être organisées de manière à conserver une correspondance claire avec leur utilisation dans le projet.

Les fichiers ne doivent pas être placés dans ce répertoire simplement parce qu'ils sont utilisés par le laboratoire.

Les scripts, configurations et exports techniques doivent rester dans leurs répertoires respectifs.

---

## 3. Principes

Les ressources ajoutées dans ce répertoire doivent :

* avoir une utilité identifiée ;
* être utilisées par la documentation ou le projet ;
* conserver un nom explicite ;
* éviter les doublons ;
* respecter les licences applicables.

---

## 4. Relation avec la documentation

Les ressources graphiques ou statiques utilisées par la documentation peuvent être référencées depuis les documents Markdown concernés.

La documentation opérationnelle et pédagogique reste située dans `docs/`.

---

## 5. Sécurité

Aucune donnée sensible, identifiant, secret, export contenant des informations personnelles ou donnée issue d'une infrastructure réelle ne doit être ajoutée à ce répertoire.

Les ressources doivent être vérifiées avant publication du dépôt.
